# Lost & Found Board - Campus

A simple mobile web app for reporting lost and found items on campus.

## Description
Students can post lost or found items, search, filter by category, and mark items as claimed. All data is saved in the browser so it works even after refresh.

## Features
- Post a Lost or Found item with photo, title, category, location, and description
- Search items by keyword
- Filter by All / Lost / Found / Claimed
- View item details
- Mark item as Claimed
- Delete an item
- Mobile-friendly design

## How to Install and Run
1. Open the live link below, or
2. Download / Clone this repository
3. Open `index.html` in any browser (Chrome recommended)
4. No installation needed - just open and use!
